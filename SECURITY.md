# Security Policy

## Our Commitment to Privacy & Security

**Appendix** is designed with a strict offline-first, local-only architecture. 

- **No Remote Telemetry**: The application does not collect, transmit, or synchronize user text or metadata to any remote server.
- **No Cloud Inference**: All AI and grammar processing occurs locally on the user's hardware.
- **Local Storage**: User history and preferences are stored locally in SQLite and remain entirely under the user's control.

## Reporting a Vulnerability

If you discover a security or privacy vulnerability:
1. Please do not report it through public GitHub issues.
2. Email the maintainer directly at: `scrollfaiyaz@gmail.com`
3. Include details of the vulnerability, steps to reproduce, and affected platforms.
4. We aim to acknowledge reports within 48 hours and provide a remediation plan promptly.
